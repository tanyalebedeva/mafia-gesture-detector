# Model card: mafia-gesture-detector (YOLOv8n)

## Назначение
Детекция и классификация жестов рук, которыми игроки «Спортивной мафии»
общаются во время игры. Задача - разметка видеотрансляций турниров
и автоматический подсчёт жестов. Модель не предназначена для судейства
и для выводов о конкретных людях.

## Данные
| | |
|---|---|
| Источник | кадры собственных видео, разные ракурсы и освещение |
| Объём | ~900 исходных изображений, после аугментации train ≈ 2500 |
| Разметка | вручную в Roboflow, формат YOLO, 9 классов |
| Разбиение | 80 / 10 / 10 (train / valid / test), test = 90 изображений |
| Аугментации (Roboflow) | шум, яркость, поворот ±15° - только train |
| Аугментации (Ultralytics, онлайн) | HSV, сдвиг, масштаб, горизонтальный флип, mosaic (выключается за 10 эпох до конца) |

Классы: `black` (мафия), `don`, `mir` (мирный), `sheriff`, `num1`–`num5`.
В исходной разметке класс 0 назван `back`. В коде это исправляется при загрузке модели (`mafia_cv/classes.py`).

## Обучение (фактические параметры из чекпоинта `models/best.pt`)
| Параметр | Значение |
|---|---|
| Базовая модель | `yolov8n.pt` (COCO), ~3 млн параметров |
| Ultralytics | 8.4.55 |
| epochs / imgsz / batch | 30 / 640 / 16 |
| optimizer | `auto` (см. «Известные проблемы») |
| lr0 / momentum (в аргументах) | 0.01 / 0.937 |
| Лосс | BCE (классы) + CIoU + DFL (рамки) |
| GPU | Tesla T4 (Colab), ~19 минут |

## Метрики

**Валидация** (лучшая эпоха 30, из чекпоинта):

| Precision | Recall | mAP@50 | mAP@50-95 |
|---|---|---|---|
| 0.969 | 0.970 | 0.975 | 0.947 |

**Test** (из отчёта): mAP@50 = **0.968**, mAP@50-95 = **0.959**.

Матрица ошибок на test (`docs/img/confusion_matrix.png`) показывает ошибки
только на цифрах: `num2 → num1`, `num3 → num4`, один пропуск `num4` и два ложных
срабатывания на фоне. Классов `num2` и `num3` в test всего 5 и 3 объекта,
поэтому их AP статистически ненадёжен.

## Известные проблемы и ограничения
1. **Вероятная утечка через кадры одного видео.** Датасет нарезан из видео,
   а разбиение 80/10/10 случайное по кадрам. Соседние кадры одного ролика почти
   одинаковы, поэтому test, скорее всего, частично «видел» train, и метрики
   завышены. Проверка: `python -m mafia_cv.leakage <датасет>`. Исправление:
   разбиение по видео (`--resplit`), переобучение, обновление этой таблицы.
2. **Подобранные гиперпараметры не применялись.** В первой версии
   `model.tune()` запускался, но финальное обучение шло с параметрами по
   умолчанию и `optimizer='auto'`. В этом режиме Ultralytics сам выбирает
   оптимизатор и learning rate, а `lr0`/`momentum` игнорирует. Исправлено
   в `mafia_cv/train.py`: явный `AdamW`, лучшие значения из тюнера
   подставляются в обучение. Веса `best.pt` пока от старого запуска.
3. **Мало участников и мало сцен.** Почти все кадры - руки 1–3 человек в домашней
   обстановке. На турнирной трансляции (другой фон, несколько рук в кадре, маски,
   дальний план) качество будет ниже. Нужна отдельная проверка.
4. **Тест маленький** (90 изображений, ~90 объектов). Доверительный интервал
   mAP - несколько процентных пунктов.

## Как воспроизвести
```bash
export ROBOFLOW_API_KEY=...
python -m mafia_cv.train --tune          # тюнинг -> обучение -> reports/metrics_test.md
```
